The Final Project transitions our testing focus from B2C storefronts to the complex, data-heavy B2B Enterprise environment of the OpenCart Admin Dashboard (https://demo.opencart.com/admin). 
The primary objective is to evaluate enterprise-grade QA capabilities by implementing advanced Playwright techniques on core administrative workflows and backend operations, strictly omitting any live B2C financial transactions or distributed load testing. 
The strategy enforces strict Page Object Model (POM) architecture and a targeted split between UI and API execution layers.
